工具箱 · 书签脚本（一键提取影视页视频直链）

在影视网站播放页运行下面的书签脚本，会自动找出视频直链并复制，然后粘贴到本页顶部输入框。

iPhone Safari 安装步骤
  1. 先全选复制下面文本框里的脚本代码（点「复制脚本」）。
  2. 用 Safari 随便打开一个网页 → 点分享按钮 → 「添加书签」，名称填「提取视频」。
  3. 打开 书签 → 编辑，找到「提取视频」，把网址整段删掉，粘贴刚才复制的脚本，保存。
  4. 在影视网站播放页 → 点地址栏 → 从书签里点「提取视频」，直链会自动复制并弹出。
Android Chrome 安装步骤
  1. 复制脚本代码；在电脑版 Chrome 上收藏任意页面，把网址替换为脚本后同步到手机；
  2. 或安装「Bookmarklet Launcher」类小工具来运行脚本（Chrome 手机版地址栏不允许直接输入 javascript:）。

常见问题与限制

  • 直链被防盗链/跨域拦截：部分网站直链需要特定来源（Referer）才能访问，会加载失败，属于站点限制，可换播放源。
  • iOS 版本：直链为 m3u8 时需 iOS 17.1+（支持 Managed Media Source）。iPhone 浏览器拿不到视频内部声音，开始识别会自动切到麦克风拾音（视频照常出声），请保持外放音量。Android Chrome 无此限制。
  • 延迟：云端识别约 1～2 秒出一句；本地模式 10 秒音频约需 2～8 秒处理，字幕会滞后一小段，可用「偏移」微调显示时机。
  • 准确率：云端 qwen3-asr-flash 支持中英日韩等多语自动识别，远超本地小模型；本地模式对嘈杂/音乐背景识别较一般，英语内容建议选英语专用模型。
  • 云端 Key：使用阿里云百炼 API（bailian.console.aliyun.com 支付宝/淘宝登录，新人各模型自动送免费额度），未充值账号额度用完即停不扣费，Key 只保存在你手机本地。
  • 保持前台：锁屏或切后台后识别会暂停，已尽量申请屏幕常亮。
